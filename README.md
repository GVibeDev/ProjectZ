# PROJECT Z

A free HTML5 shoot 'em up inspired by 1990s arcade games, by **G-VIBE DEV**.

**[Play on itch.io](https://gvibedev.itch.io/projectz)** · **[Play directly in your browser](https://gvibedev.cc/ProjectZ/)**

## Release Candidate 1

Project Z **RC1** is approved for external playtesting. This repository hosts the public web Runtime, including local couch co-op.

The frozen RC1 game revision is [`ff12c07`](https://github.com/GVibeDev/ProjectZ/commit/ff12c070da82f834917779f68cfc0ff334860e18). Later documentation commits do not change that game revision or its sealed packages. Original build labels may still contain `FINAL-UI-R1` or `CANDIDATE`.

Follow the in-game control hints and binding settings. Compatibility with physical Android devices and gamepads is still being validated.

## Feedback

Report problems through [GitHub Issues](https://github.com/GVibeDev/ProjectZ/issues) or the [itch.io project page](https://gvibedev.itch.io/projectz). Include:

- Browser and version, operating system, device and controls.
- Difficulty, solo/local co-op, Stage and the moment the problem occurred.
- Steps to reproduce, expected behaviour and observed behaviour.

For a temporary freeze, also note its approximate duration and whether audio and input continued. The historical freeze report remains under observation; no freeze was observed in the designer's R2 playtest.
